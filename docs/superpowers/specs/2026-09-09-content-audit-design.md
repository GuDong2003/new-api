# 内容审计设计

更新日期：2026-09-10
状态：单实例精简、保存生成原图及只按全站总容量保存已完成本地实现、验证和独立审查；用户已授权提交、推送和部署。本稿替代此前的多实例方案和固定图片大小/张数限制。

## 1. 目标

只服务一个 New API 实例。root 在设置中开启后，记录全站用户的新请求，按用户查看：

- 用户发出的文本、提示词和生成参数；
- 模型返回的文本，包括普通响应和流式响应；
- 生成图片的结果地址、原始图片字节及用于快速浏览的缩略图。

关闭后停止新采集，不删除历史记录；开启前的内容不补录。内容审计独立于计费、用量和安全日志，采集故障不能改写或中断原请求。过载时允许丢弃审计副本，不承诺无损记录。

## 2. 部署边界

- 仅支持一个活跃 New API 进程使用这套审计数据库和目录。重启、升级时先停止旧实例，不支持多个实例同时访问。
- 正文、原图和缩略图使用本机私有持久化目录，由 `CONTENT_AUDIT_STORAGE_DIR` 指定；容器部署需挂载持久卷。不能把数据放在容器临时层、公开静态目录、请求缓存或备份目录中。
- 复用既有加密封装、目录标记、元数据及读取接口，不重置存储，不删除历史记录。
- 不需要节点注册、跨节点心跳、共享文件互读探针、集群就绪判定或清理任务跨节点接管。
- 保留本机目录权限、存储身份、稳定密钥及可用空间检查；这些保护不依赖集群。
- 主库仍兼容 SQLite、MySQL 和 PostgreSQL。没有审计专用跨主机文件系统或新的存储服务。

## 3. 支持范围

| 接口 | 记录内容 |
| --- | --- |
| Chat Completions / Completions | 普通及流式文本、工具调用、结束信息 |
| Responses / Responses compact | 普通及流式文本；最终 `image_generation_call.result` 保存原图和可选预览，重复结果去重，中间 partial image 不当作最终图片 |
| Claude Messages | 普通及流式内容块、工具调用及工具结果 |
| Gemini generateContent / streamGenerateContent | 候选文本、函数调用、输出 `inlineData` / `inline_data` 图片 |
| OpenAI 图片生成、编辑及现有绘图入口 | 提示词、参数、脱敏结果地址及 URL/base64 输出的原图和可选预览 |

不为输入附件保存原图，不把音频或普通工具结果当成生图。图像原始 base64 不放进审查正文。异步任务插件、历史离线任务、视频、语音、Realtime 和第三方跳转对话不在本期补充范围。

## 4. 设置与资源限制

| 项目 | 默认值 | 约束 |
| --- | --- | --- |
| 全站采集 | 关闭 | root 显式开启，初始化不自动开启 |
| 保存期限 | 7 天 | 1～30 天；新设置用于新记录 |
| 单条请求正文 | 512 KiB | 64 KiB～2 MiB |
| 单条响应正文 | 1 MiB | 64 KiB～4 MiB |
| 审计容量 | 512 MiB | 64 MiB～10 GiB |
| 生成原图 | 随采集保存 | 不设单张字节数、每次张数、每用户配额或独立图片容量池；保留收到的原始字节 |
| 图片预览 | 开启 | 派生缩略图最长边 1024 px、输出不超过 300 KiB；关闭只影响预览，不影响原图保存 |
| 预览解码 | 每边不超过 8192 px、总像素不超过 16,777,216 | 仅限制派生预览的资源消耗；无法安全解码时仍可保留已验证容器的原图 |
| 活跃捕获、待写队列 | 各最多 64 条 | 捕获和待写输入共用 64 MiB 预算 |
| 后台写入、图片解码 | 2 / 1 个 worker | 不随请求数无限创建 goroutine |

原图、缩略图、正文、描述文件、加密封装及在途写入共同占用同一 `CapacityBytes`。写入前逐步预约实际所需容量，并发不能超订；取消 95%/80% 容量迟滞及 100,000 条记录准入门槛。大图无法容纳时不应长期阻止余量内的小图或正文。原图优先于派生预览；不足时允许保存已有完整图片和正文，并明确标记省略/失败。

保留期限、下载超时、格式/来源校验、运行时有界队列和真实磁盘余量保护。队列繁忙可能丢弃审计副本，但不得以更大的固定字节数/张数替代已取消的业务上限。正文仍按现有可配置长度截断，截断或正文节点预算耗尽后继续流式提取生成图片，不保留 64 MiB 累计图片扫描上限。

容量统计包括在途预留和实际审计文件，不等于主数据库物理页或整个 VPS 用量。数据库、Docker 镜像、缓存及其他服务的文件不在此功能的清理范围。

## 5. 本机写入与恢复

- 复用现有旁路捕获和有界队列，HTTP relay 不等待审计文件写入或图片下载。
- 后台文件写入与本机维护通过运行时锁协调；维护不能删除仍在写入或被原图读取句柄占用的当前进程文件，也不能提前释放其容量。内部写入共享真实磁盘余量检查与写入边界。
- 配置版本、采集 epoch、记录状态条件和短数据库事务继续防止过期任务写入及并发重复扣减。这些是单机并发保护，不作为日常界面诊断项展示。
- 启动恢复在新写入准入之前处理旧进程未完成记录。依据本稿的单进程部署契约，旧实例此时已经停止；不能把多实例部署误当作支持场景。
- 保留原子文件发布、加密完整性检查、幂等删除、失败重试、孤儿文件核对及未知文件保护。重启不能清空已完成记录或重置容量统计。
- 本机维护按小时检查到期记录；初始化、删除请求或容量恢复需要时合并唤醒，不创建重复清理任务。
- 停止服务时先停止准入，等待/取消所属后台工作，不能在 HTTP writer 仍活跃时关闭它依赖的队列。
- 移除审计专用的分布式清理所有权与节点表写入。不改动项目通用任务调度框架，不执行 DROP TABLE，也不删除旧表中的数据。
- 原图使用固定工作缓冲、逐块复用既有 NACA0001 加密封装；新流式容器含序号、长度、摘要和经认证结束记录，不产生明文暂存。旧 namespace、密钥派生和旧正文/缩略图继续可读。
- 图片描述采用一张分页索引子表及有界加密描述文件，主记录和闭合标记不持有无界清单。原图/描述/预览均先计入预约，失败删除确认后才回收占用。清理按批扫描任意数量的合法文件，遇未知文件/链接保留原保护行为。
- 完整校验文件归属后，在现有审计记录上持久化有界、加密的删除授权及阶段；图像删除并同步后才进入元数据阶段。清理中断后可验证剩余文件并继续，不能仅凭“删除中”状态放行未知文件。该信息不新增用户配置，也不暴露在管理接口中；子记录和占用仅在确认物理删除后释放。
- 剩余文件检查使用现有图片索引表上的最少量私有反查字段及索引，避免每个目录批次重扫全部描述文件；反查仅用于定位，不能替代加密描述及归属验证。旧索引按需安全补齐，不保存来源网址或凭据，不增加表、服务或图片数量上限。

## 6. 权限与隐私

- 仅允许有效 root 后台会话访问设置、列表、正文、图片和删除接口；不能以 API token、过期会话或前端隐藏代替服务端鉴权。
- 保留初始化、修改设置及删除的现有敏感操作证明和重放防护；不新建一套身份验证流程。
- 密钥、密码、认证头、Cookie 等凭据字段脱敏；自由文本按原意显示，不因为包含普通单词而任意改写。
- 正文按需加载，列表只返回元数据。敏感接口使用 no-store；页面退出、权限失效或删除后清理正文缓存和 Blob URL。
- 返回内容作为纯文本或安全结构渲染，不能执行用户消息中的 HTML/脚本。
- 图片下载继续使用既有 SSRF、重定向、TLS、无凭据转发和超时保护；不保留独立原图字节上限。预览解码资源限制与原图保存分离。
- 保留稳定密钥加密。缺少稳定密钥时不能静默降级；如选择已有明文模式，仍须显式确认和私有目录保护。
- 查看、下载及删除行为保留现有安全访问留痕，不能把消息正文再次写进通用日志。

相关依据：[OWASP Authentication](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)、[Session Management](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)、[SSRF Prevention](https://cheatsheetseries.owasp.org/cheatsheets/SSRF_Prevention_Cheat_Sheet.html)。这是本功能的安全边界，不是全量 ASVS 合规声明。

## 7. 页面与接口

保留现有内容审计页面和用户/时间/模型等筛选、请求/响应详情、图片预览与删除功能。

设置页保留采集开关、保存天数、容量及单条正文限制、缩略图开关。状态区域仅展示采集状态、已用空间/上限、记录数、最近清理和需要处理的异常。

移除节点列表、集群就绪、共享预检、命名空间、配置版本、密钥指纹及预留槽位等日常技术信息。加密缺失或空间不足等真正影响使用的问题仍明确提示。

状态接口用 `ready` 表示本机可用性，不返回 `nodes`、`missing_nodes`、`cluster_ready`。本机可以在采集关闭时就绪；开启但未就绪时显示暂停。现有初始化、保存、列表、详情、缩略图和删除接口及操作证明结构不变；移除仅服务集群的 `/preflight`。

详情返回首批图片和后续游标；增加同一 root/session 保护组下的图片分页及原图流式读取接口，移除缩略图索引只能 0～3 的限制。原图经完整性验证、访问留痕及发送前再次鉴权后输出，长传输遇撤权/到期停止；不把令牌放 URL，不使用公开图片目录。旧记录明确显示未保存原图。

默认只加载预览；支持的浏览器通过文件流写入下载原图。查看原图按需、一次一张，退出/删除/权限失效及时回收资源。浏览器解码大图仍会消耗内存；不支持流式文件保存时显示能力说明，不把整图 Blob 缓冲谎称为有限内存下载。此浏览器能力边界不限制服务端留存。

设置状态每 60 秒在可见页面刷新，也可手动刷新。后台页面不轮询；刷新不能丢掉尚未保存的表单内容。中文界面使用简短中文，不出现站点专属示例。

## 8. 验收与交付边界

- 从无节点登记、无 master 协调的本机存储完成初始化、就绪、开启、采集、读取和删除。
- 重启后旧 pending 不再永久占用容量或阻塞新写入；已有完成记录仍可读取；本轮活跃 writer 不被维护误删。
- 普通及流式文本、Responses/Gemini/OpenAI 生图、容量/期限、权限/脱敏、图片安全及原始 relay 字节回归；实测超过 10 MiB 的原图、第 6 张图片、正文截断后图片和累计超过 64 MiB 的有效图片输出。
- 断点/取消/重启/删除保守回收；加密块缺尾、篡改和换序拒绝；原图 SHA-256/字节长度与输入一致；多用户并发共用容量且不越限；旧格式记录继续读取及清理。
- SQLite、MySQL、PostgreSQL 实际新库与升级验证；保留既有独立日志库路径验收。移除只为多节点语义存在的测试，不以删除断言掩盖单机问题。
- 前端测试、类型检查、lint/format、构建，以及桌面/手机设置页验证。
- 所有测试产物放在外置盘 .build；本轮不触碰真实用户内容，不调用付费 provider，不修改生产配置。
- 用户已另行授权提交、推送和部署：在 main 发布新的版本 tag，使用通过 CI 的 Docker 镜像，部署前备份现有数据库和配置；保留数据卷、稳定密钥及回滚镜像，不自动开启全站采集。
